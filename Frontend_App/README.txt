COLLEGE EVENT MANAGEMENT SYSTEM - FRONTEND APP

How to run:
1. Open index.html in Google Chrome, Microsoft Edge, or another modern browser.
2. No server or installation is required for the current frontend demo.
3. The frontend displays sample project data and includes Dashboard, Students,
   Organizers, Events, Registrations, Attendance, and Student CRUD sections.
4. The Student CRUD operations in this frontend are client-side/demo operations;
   they do not automatically write to the MySQL database.
