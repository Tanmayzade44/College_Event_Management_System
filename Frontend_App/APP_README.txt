COLLEGE EVENT MANAGEMENT SYSTEM - FRONTEND APPLICATION

RUN THE APP:
1. Double-click Run_Frontend_App.bat on Windows.
2. It opens index.html in your default web browser.
3. You can also double-click index.html directly.

FILES:
- index.html : runnable frontend application
- College_Event_Management_System_Frontend_Source.html : source-code copy
- Run_Frontend_App.bat : one-click Windows launcher
- README.txt : usage information

NOTE:
This is a standalone browser frontend/demo. Its CRUD operations are client-side
JavaScript and are not connected directly to the MySQL database.
