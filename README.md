# College Event Management System

A DBMS mini-project for managing college events. This repository contains the frontend application, SQL/DBMS project documents, ER diagrams, screenshots, and project documentation.

## Project Contents

- `index.html` — main frontend application (GitHub Pages entry point)
- `Frontend_App/` — complete frontend app with source file, README, and Windows launcher
- `Screenshots/` — project output and ER-model screenshots
- `College_Event_Management_System_19_Queries.pdf` — SQL query collection
- `College_Format_DBMS_Mini_Project_CRUD_Updated.pdf` — college-format project documentation

## Run the Frontend

### Option 1: Browser
Open `index.html` in Google Chrome, Microsoft Edge, or another modern browser.

### Option 2: Windows
Open `Frontend_App/Run_Frontend_App.bat`.

### Option 3: GitHub Pages
1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save.

GitHub will provide a live website link after deployment.
